# Design Sanctuary

Build a complete premium Interior Design Studio platform from the user's specification. Create one connected system with: a cinematic public portfolio website, powerful admin/studio operations workspace, and a calm secure client portal. Prioritize exceptional visual design, easy multi-project management (25–30 active projects), media/document workflows, and professional client experience. Use Lovable Cloud for real authentication, database, storage, RBAC, and backend workflows; do not use the supplied mongodb://localhost:27017/ connection because it is local-only and cannot serve a deployed app. Start by inspecting the generated repository and establish the product architecture, normalized schema, role model, design system, and real seed data. Then implement the end-to-end core flow: web enquiry → CRM lead → client/project → rooms/tasks/design uploads → approval workflow → BOQ/quotation → invoices/payment tracking → procurement/site updates → client portal → publishable portfolio case study. Include functional media library, CMS, project dashboard, roles, notifications, responsive layouts, SEO foundations, audit log architecture, and no dead/fake buttons. Use polished realistic seed data and premium architectural/editorial styling, with clearly distinct public/admin/client experiences. Build iteratively, validate after phases, and make all important interactions persist through the backend.
